# Clareza — API

API do sistema de organização financeira pessoal Clareza.

## Stack

- Java 8
- Spring Boot 2.7.18
- PostgreSQL 16 + Flyway
- Arquitetura hexagonal (Clean Architecture)

## Requisitos

- JDK 8
- Maven 3.8+
- Docker (para o banco local)
